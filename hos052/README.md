# AgroGuard AI - Advanced Plant Disease Detection & Smart Farming Assistant

Course: Professional Training (YN3012170034) - Mid-term Project
Student folder: hos052

> This README will be completed step by step as the project grows.

## Features (planned)
1. Plant leaf disease detection from an uploaded image
2. Explainable AI heatmap (Grad-CAM)
3. Smart farming advice (cause, treatment, prevention) in English and Bangla
4. Crop recommendation from soil and weather values

## Project structure
- `src/` - application source code
- `notebooks/` - model training / fine-tuning notebooks
- `assets/` - screenshots and sample images
- `data/` - datasets (not uploaded, see instructions below)
- `models/` - trained model files (not uploaded, see instructions below)
